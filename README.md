# 📰 Duna News

**Duna News** é uma aplicação web moderna que exibe as principais notícias do momento no formato de **feed de rede social**, inspirada no *Design System* minimalista e elegante da **Apple**.

> ⚡ **Consumo de Dados em Tempo Real:** Todas as notícias exibidas na plataforma são fornecidas e atualizadas em tempo real via [NewsAPI.org](https://newsapi.org/).

---

## ✨ Funcionalidades

- 📱 **Feed Estilo Rede Social:** Notícias apresentadas em formato de cards interativos.
- 🎨 **Design Inspirado na Apple:** Interface limpa com suporte a *Glassmorphism*, cantos arredondados e animações fluidas.
- 🏢 **Identificação de Fontes:** Exibição automática da logo real do veículo de imprensa (G1, UOL, TechCrunch, etc.) via favicon do Google.
- 🏷️ **Filtro por Categorias:** Navegação rápida por Tecnologia, Negócios, Esportes, Entretenimento, Saúde e Ciência.
- ❤️ **Interatividade Local:** Funcionalidade de curtir publicações e adicionar comentários nos cards.
- 🔗 **Acesso Direto:** Link rápido para ler a matéria completa diretamente na fonte original.
- 📱 **Totalmente Responsivo:** Layout adaptado para dispositivos móveis, tablets e desktops.

---

## 🛠️ Tecnologias Utilizadas

- **[React](https://react.dev/)** — Biblioteca JavaScript para construção da interface.
- **[Vite](https://vitejs.dev/)** — Build tool ultra-rápida para desenvolvimento front-end.
- **[CSS3 NATIVO](https://developer.mozilla.org/pt-BR/docs/Web/CSS)** — Estilização personalizada com variáveis CSS e efeito *Glassmorphism*.
- **[Lucide React](https://lucide.dev/)** — Coleção de ícones modernos e leves.
- **[NewsAPI](https://newsapi.org/)** — API REST para busca de notícias em tempo real.
