# 📰 Duna News

**Duna News** é uma aplicação web moderna que exibe as principais notícias do Brasil e do mundo no formato de **feed de rede social**, inspirada no *Design System* minimalista e elegante da **Apple**.

> ⚡ **Consumo de Dados em Tempo Real:** As notícias são obtidas diretamente do **Google News Brasil** via RSS e convertidas para JSON em tempo real, garantindo alta disponibilidade, zero custos e sem bloqueios de CORS no GitHub Pages.

---

## ✨ Funcionalidades

- 📱 **Feed Estilo Rede Social:** Notícias apresentadas em cards interativos e responsivos.
- 🎨 **Design Inspirado na Apple:** Interface limpa com efeito *Glassmorphism*, cantos arredondados e animações fluidas.
- 🏢 **Identificação de Fontes:** Exibição do logotipo oficial do veículo de imprensa via favicon do Google.
- 🏷️ **Filtro por Categorias:** Navegação rápida por Tecnologia, Negócios, Esportes, Entretenimento, Saúde e Ciência.
- ❤️ **Interatividade Local:** Funcionalidade de curtir publicações e adicionar comentários nos cards.
- 🔗 **Acesso Direto:** Link rápido para ler a matéria completa diretamente na fonte original.
- 🚀 **Pronto para o GitHub Pages:** Sem necessidade de chaves de API privadas ou proxies de terceiros.

---

## 🛠️ Tecnologias Utilizadas

- **[React](https://react.dev/)** — Biblioteca JavaScript para construção da interface.
- **[Vite](https://vitejs.dev/)** — Build tool ultra-rápida para desenvolvimento front-end.
- **[CSS3 NATIVO](https://developer.mozilla.org/pt-BR/docs/Web/CSS)** — Estilização personalizada com variáveis CSS e efeito *Glassmorphism*.
- **[Lucide React](https://lucide.dev/)** — Coleção de ícones modernos e leves.
- **[Google News RSS](https://news.google.com/)** + **[rss2json](https://rss2json.com/)** — Fonte confiável e sem restrições de CORS para atualização de notícias.
